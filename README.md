This repository was set up using [chezmoi](https://github.com/twpayne/chezmoi).
## Quick start
To initialise `chezmoi` with a single command:
```bash
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply https://codeberg.org/jvssdev/dotfiles.git
```
To update after initialisation:
```bash
chezmoi update
```
